## Что означают предупреждения валидатора

Тринадцать исходных побочных квестов и развилка `m10` не помечают последнее условие специальным словом `fallback`. Движок по своему действующему правилу выбирает последний исход как запасной. Это не отсутствие текста и не ссылка на несуществующую сцену. Валидатор поэтому выдаёт предупреждения, но ошибок нет. Сквозные маршруты проверяют, что эти предупреждения не запирают основную линию.

## Границы проверки

Проверки выполнены в Chromium на Linux. Сквозной бот проходит настоящие игровые сцены, выборы, расследования и обработчики квестов, однако перемещается телепортацией и мгновенно добивает врагов. Он проверяет связность и доступность сюжетной цепочки, а не баланс боя, удобство ручного прохождения каждого участка или длительность игры. Предполагаемый «мирный» маршрут по умолчанию выбирает неагрессивные реплики там, где это предусмотрено, но не гарантирует отсутствие всех обязательных боёв.

Каждая из семи концовок проверена на уровне условий. Два полных прохождения — это не семь исчерпывающих ручных прохождений всех комбинаций и не тест всех 56 побочных квестов. Android/iOS и конкретные настольные версии Firefox/Safari физически не проверялись. Мобильный адаптивный интерфейс проверен в эмуляции сенсорного устройства.

Сохранения локальные; стабильность `localStorage` для переименованного HTML и приватного браузера зависит от браузера. Для надёжного переноса предусмотрен скачиваемый JSON. На телефоне лучше размещённая HTTP-версия, поскольку локальные большие HTML-файлы поддерживаются не везде.

В сборке нет сервера, учётных записей и аналитики удержания. Повторяемые задания, разные миры, выборы, сцены памяти, достижения и постоянный альбом создают причины возвращаться, но фактическую вовлечённость, баланс и популярность нужно оценивать по реакции настоящих игроков.

## Воспроизведение проверок

После установки зависимостей через `npm install --prefix tools/node`:

```bash
node tools/build_ink.mjs
node tools/validate_story.mjs
node --experimental-default-type=module --test tests/*.test.mjs
node tools/build_release.mjs
python3 -m http.server 8765
```

При запущенном сервере во втором терминале:

```bash
node tests/release_smoke.mjs
node tests/expansion_browser.mjs
OUT=./out/peaceful/ node tests/story_release.mjs human peaceful 6 1
OUT=./out/violent/ node tests/story_release.mjs human violent 6 2
```

Браузерные тесты используют Chromium по пути `/usr/bin/chromium`. На другой ОС замените `executablePath` на доступный Chromium или используйте браузер Playwright после его установки. Скриншоты и JSON-результаты записываются в `out/`. Исторические боты `t*.mjs` сохранены из исходного проекта, но отчёт выпуска относится к новым `release_smoke.mjs`, `expansion_browser.mjs` и `story_release.mjs`.
