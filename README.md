# Пряжа

Браузерная сюжетная RPG — тихая северная сказка о памяти, нитях и долгах. Герой просыпается в реке у
Ольхового Брода обычным человеком, без ремесла и без имени. Старуха Агафья зовёт его чужим именем, деревня
не жалует чужаков, а на кладбище кто-то разрывает могилы.

**Играть:** https://wwgame28.github.io/pryazha/ (работает после включения GitHub Pages, см. ниже)

## Что в игре
- **Сюжет на ink.** Полностью прописанные диалоги, ремарки, выборы с последствиями. Арка из 6 глав: глава 1
  написана заново; главы 2–6 сейчас играются по исходной основной линии, новые сцены для них пишутся.
- **Последствия.** Репутация у фракций, отношения с людьми (доверие, страх, уважение, вражда), свидетели
  поступков, слухи (в том числе ложные), которые расходятся по деревне и гаснут, обещания и долги,
  предательства, отложенные события. Торговцы — участники истории: закрываются, меняют цены, прощают.
- **Старт человеком.** Класса в начале нет. Путь воина, следопыта, ткача, мага и других выучивается у
  наставников по сюжету.
- **Трудный бой.** На старте 13–17 здоровья, враг убивает за 3–4 удара. Отскок и парирование: красный «!»
  над врагом — замах, его можно отбить; «‼» — тяжёлый удар, только отскочить. Выносливость, медленная прокачка.
- **Костры.** Редкие точки отдыха: здоровье, зелья, сохранение; после гибели — пробуждение у последнего костра.
- **Живой мир.** Течёт река, гнётся трава, дымят трубы, днём бабочки, ночью светлячки; дождь, туман, снег;
  звуки реки, ветра, птиц и сверчков.

## Управление
| | Клавиатура | Телефон |
|---|---|---|
| Ходьба | WASD / стрелки | палец в левой части экрана |
| Атака | J | ⚔ |
| Отскок | Пробел | ↷ |
| Парирование | H | ⛨ |
| Навыки | K, L, U, I | кнопки вокруг атаки |
| Действие (говорить, отдохнуть у костра) | E | ◉ |
| Захват цели | F, G — следующий | ◎ |
| Зелья | 1, 2 | ♥, ♦ |
| Меню | Esc / Tab | ☰ |

## Как включить GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)**
→ Save. Через минуту-две игра откроется по ссылке выше. На iPhone: Safari → «Поделиться» → «На экран „Домой“».

## Запуск у себя
```bash
python3 -m http.server 8000   # из корня репозитория
# открыть http://localhost:8000/
```

## Разработка
| Что | Команда |
|---|---|
| Зависимости инструментов (ink-компилятор) | `npm install --prefix tools/node` |
| Собрать сюжет из `site/narrative/*.ink` | `node tools/build_ink.mjs` |
| Проверить связи сюжета (0 ошибок обязательно) | `node tools/validate_story.mjs` |
| Документы переменных, квестов, непрерывности | `node tools/gen_docs.mjs` |
| Тест ядра последствий | `node tests/world_state.test.mjs` |
| Сюжетный бот, бой, костры (нужен Playwright) | `bash mktest.sh && python3 -m http.server 8765 --directory site` и в другом окне `node tests/t24.mjs human first 1` (а также `t10`, `t25`–`t28`) |

Как писать сцены и квесты — `docs/WRITING_GUIDE.md`. Канон мира — `docs/STORY_BIBLE.md`, арка — `docs/STORY_ARC.md`,
главы — `docs/CHAPTERS/`, переменные выбора — `docs/CHOICE_FLAGS.md`, квесты — `docs/QUESTS.md`,
ход работы — `docs/PROGRESS.md`.

## Устройство
```
index.html            страница для GitHub Pages (ресурсы берутся из site/)
site/                 игра: game.js, story.js (квесты), narrative.js (мост к ink), world_state.js (последствия),
                      life.js / weather.js / ambient.js (анимации, погода, звуки), story.json, narrative/, ассеты
docs/                 дизайн-документы
tools/                сборка ink, проверка связей, генерация документов, слияние глав
tests/                боты и тесты
licenses/             файлы лицензий авторов ассетов
```
