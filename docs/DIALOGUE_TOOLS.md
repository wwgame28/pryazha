# Инструменты диалогов: Yarn Spinner, Ink, Inky (этап 5)

## Что проверялось
Нужна система, которая работает в браузере без сборки (в том числе в Safari на iPhone), умеет условия,
ветвления, внешнее состояние игры, сохранение и не требует .NET/Unity.

| | Yarn Spinner | Ink | Inky |
|---|---|---|---|
| Репозиторий | github.com/YarnSpinnerTool/YarnSpinner | github.com/inkle/ink | github.com/inkle/inky |
| Лицензия | MIT | MIT | MIT |
| Официальный рантайм | C#/.NET; пакеты для Unity (также Godot, Unreal) | C# (+ компилятор inklecate) | — (это редактор) |
| Рантайм для браузера | официального нет. Сообщество: bondage.js (MIT, Yarn 1, Yarn 2 частично), yarn-bound (ISC, 2024), **yarnspinner-typescript** (CC0, v1.1.0, создан 14.09.2026, один автор) | **inkjs** (MIT, v2.4.0, без зависимостей; его использует веб-экспорт самого Inky) | — |
| Компилятор без .NET | только в порте сообщества | да: `inkjs/full` содержит компилятор, работает в Node | встроен (inklecate) |
| Сохранение состояния | в порте — не проверено на зрелость | `story.state.toJson()` / `LoadJson()` | — |
| Редактор | VS Code-расширение, Try Yarn Spinner (веб) | любой текстовый + Inky | десктоп: Windows/Mac/Linux (Electron), **на iPhone/iPad нет** |

## Прототипы (папка `tools/proto/`)
Одна и та же сцена (`m4_agafya_plea`, мольба Агафьи перед Проводами) написана на обоих языках.

**Ink** (`proto.ink`, `proto_run.mjs`, `proto.html`):
- компиляция в Node — 78 мс, 0 ошибок, JSON 3,4 КБ;
- метаданные сцены (место, время, участники, условие запуска) — теги в начале узла, читаются через
  `TagsForContentAtPath`;
- условия реплик и вариантов через внешние функции (`trust("agafya") >= 2`), изменения состояния
  (`set`, `rel`, `promise`), выбор следующего шага квеста (`go("s3")`) — работают;
- сохранение и загрузка состояния — 429 байт JSON;
- реакция на нарушенное обещание в хабе разговора — работает;
- в браузере (Chromium, ES-модуль `ink.mjs`, 128 КБ) сцена играется без ошибок.

**Yarn** (`proto.yarn`, `proto_yarn.mjs`, порт yarnspinner-typescript): компилируется (24 мс) и выдаёт
события строк и вариантов. Но порт существует месяц, у него один автор, а официальный тулчейн Yarn
Spinner — C#/Unity.

## Решение
**Ink + inkjs — единственная система диалогов.** Yarn Spinner не подключаю: две системы
дублировали бы друг друга, а надёжного браузерного рантайма у Yarn нет. **Inky** — необязательный
инструмент автора: файлы `site/narrative/*.ink` открываются в нём на компьютере, сцены можно
проигрывать. Внешние функции там подменяются запасными (fallback), которые возвращают значения по
умолчанию.

Что это даёт на практике:
- реплики пишутся как сценарий (`agafya: …`), а не как JSON;
- компилятор ловит битые переходы и «висящие» концы на этапе сборки;
- счётчики посещений позволяют отвечать «ты это уже спрашивал» без лишних флагов;
- состояние диалогов сохраняется штатно.

## Как встроено
- Исходники: `site/narrative/*.ink` (общий файл с внешними функциями + по файлу на главу).
- Сборка: `node tools/build_ink.mjs` → `site/narrative/story.ink.json` и автоматический указатель
  сцен `docs/SCENES.md`. Ошибка или предупреждение компилятора останавливают сборку.
- Рантайм: `site/vendor/ink.mjs` (inkjs 2.4.0, лицензия в `site/vendor/INKJS-LICENSE.md`).
- Мост: `site/narrative.js` — запускает сцену, рисует диалоговое окно, привязывает внешние функции к
  состоянию мира (`site/world_state.js`), сохраняет состояние ink вместе с сохранением игры.
- Квесты остаются в `story.json` (шаги, цели, места, награды). Шаг ссылается на сцену ink. Старые
  реплики из `story.json` перенесены в ink дословно, поэтому диалоговая система одна.

## Ограничения (честно)
- На настоящем iPhone не проверено: в окружении есть только Chromium. Код ink — ES2015
  (классы, модули), их поддерживает Safari 11+.
- Inky есть только для компьютера. Править диалоги на телефоне можно лишь как текст.
